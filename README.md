## 日本語

### ゲーム名

AETHERBREAKER

### 概要

AETHERBREAKERは、スマートフォンでもPCでも遊べる縦長画面のブラウザ向けアクションシューティングです。
サーバーや追加インストールは不要で、index.html をブラウザで開くだけで動作します。

### 動作環境

- 最近のブラウザで動作します。
- 推奨ブラウザ: Google Chrome, Microsoft Edge, Safari, Firefox
- PC: デスクトップブラウザ
- スマートフォン: モバイルブラウザ
- ローカルストレージが有効なブラウザでセーブデータを保存できます。

### 遊び方

1. index.html を任意のフォルダに保存します。
2. ファイルをダブルクリックするか、ブラウザで index.html を開きます。
3. タイトル画面でゲームスタートまたは続きからを押すと開始できます。
4. ステージ選択画面では、解放済みステージを選んで始められます。
5. 画面は縦長で、スマートフォン向けに調整されています。

### 操作方法

PC

- WASD または矢印キー: 移動
- Shift: ダッシュ
- P または Esc: 一時停止
- 射撃は自動照準です。

スマートフォン

- 画面をドラッグ: 移動
- 右下の DASH ボタン: ダッシュ
- 射撃は自動照準です。

### 対応言語

ゲーム内言語は次に対応しています。

- 日本語
- English
- 中文
- Español

タイトル画面上の言語ボタンで切り替えられます。
初回は端末の言語設定に応じて、日本語、English、中文、Español のいずれかを選択します。

### サウンド

ゲーム上部のサウンドボタンで、効果音とシステム音を ON / OFF にできます。
一部のブラウザでは、最初に画面をタップしたあとに音が出ます。

### セーブデータ

セーブデータはブラウザのローカルストレージに保存されます。
対応内容は次のとおりです。

- 解放済みステージ
- ステージ別ハイスコア
- サウンド設定
- 言語設定
- 続きから機能

サーバーには保存されません。
ブラウザデータを削除すると、セーブデータも削除されます。

### ゲーム仕様

- ステージ: 全24ステージ
- 敵の種類: 16種類
- ボスの種類: 8種類
- 縦長ポートレート表示
- パーティクル効果とシールド表現
- 画面シェイク
- 自動照準システム
- ローカルセーブ
- サウンド ON / OFF
- 多言語対応

### トラブル対策

音が鳴らない場合

1. ゲームを一度タップまたはクリックしてください。
2. 上部のサウンドボタンが ON になっているか確認してください。
3. ブラウザの設定でサウンドを許可してください。

セーブされない場合

1. ブラウザの Cookie / サイトデータ / ローカルストレージ を許可してください。
2. シークレットモードではなく通常モードで開いてください。
3. 別のブラウザで試してください。

ゲームが動かない場合

1. ブラウザを最新にしてください。
2. ファイル名が index.html になっているか確認してください。
3. ファイルをブラウザにドラッグして開いてください。

## English

### Game Name

AETHERBREAKER

### Overview

AETHERBREAKER is a portrait-oriented browser action shooter that works on both smartphone and PC.
No server is required. Save the file as index.html and open it in a browser.

### Requirements

- Works in modern browsers.
- Recommended browsers: Google Chrome, Microsoft Edge, Safari, Firefox
- PC: desktop browser
- Smartphone: mobile browser
- Save data uses browser local storage.

### How to Play

1. Save the file as index.html.
2. Double-click the file or open index.html in your browser.
3. Press Start on the title screen.
4. You can also continue from the highest unlocked stage.
5. Select an unlocked stage from the stage select screen.

### Controls

PC

- WASD or arrow keys: move
- Shift: dash
- P or Esc: pause
- Shooting is automatic.

Smartphone

- Drag the screen: move
- DASH button: dash
- Shooting is automatic.

### Supported Languages

The game supports these languages.

- Japanese
- English
- Simplified Chinese
- Spanish

Use the language button at the top of the title screen.
On first launch, the game detects your browser language and selects Japanese, English, Simplified Chinese, or Spanish when possible.

### Sound

Sound and system tones can be toggled with the sound button at the top.
Some browsers require a first tap or click before sound starts.

### Save Data

Save data is stored in browser local storage.
It includes:

- unlocked stages
- best score per stage
- sound setting
- language setting
- continue function

Data is not stored on a server.
Deleting browser data will delete game progress.

### Features

- 24 stages
- 16 enemy types
- 8 boss types
- portrait layout
- particle effects
- shield visuals
- screen shake
- auto-aim shooting
- local save
- sound on / off
- multilingual support

### Troubleshooting

No sound

1. Tap or click the game once.
2. Confirm the sound button is ON.
3. Allow sound in browser settings.

Save does not work

1. Allow local storage or site data.
2. Do not use private browsing.
3. Try another browser.

Game does not run

1. Update your browser.
2. Confirm the file name is index.html.
3. Drag the file into the browser.

AETHERBREAKER es un juego de acción con vista superior, diseñado en pantalla vertical para funcionar en smartphone y PC.
No requiere servidor. Guarda el archivo como index.html y ábrelo en un navegador.

### Requisitos

- Funciona en navegadores modernos.
- Navegadores recomendados: Google Chrome, Microsoft Edge, Safari, Firefox
- PC: navegador de escritorio
- Smartphone: navegador móvil

### Cómo jugar

1. Guarda el archivo como index.html.
2. Haz doble clic en el archivo o ábrelo en el navegador.
3. Pulsa Start en la pantalla de título.
4. También puedes continuar desde el último nivel desbloqueado.
5. Puedes elegir un nivel desbloqueado desde la selección de niveles.

### Controles

PC

- WASD o flechas: mover
- Shift: dash
- P o Esc: pausa
- El disparo es automático.

Smartphone

- Arrastrar la pantalla: mover
- Botón DASH: dash
- El disparo es automático.

### Idiomas compatibles

El juego admite estos idiomas.

- Japanese
- English
- Simplified Chinese
- Spanish

Cambia el idioma con el botón situado en la parte superior del título.
En el primer inicio, el juego intenta detectar el idioma del navegador y elegir japonés, inglés, chino simplificado o español.

### Sonido

El sonido puede activarse o desactivarse con el botón de sonido en la parte superior.
Algunos navegadores requieren un primer toque o clic antes de reproducir sonido.

### Guardado

El progreso se guarda en almacenamiento local del navegador.
Incluye:

- niveles desbloqueados
- mejor puntuación por nivel
- ajuste de sonido
- ajuste de idioma
- función continuar

No se guarda en un servidor.
Si borras los datos del navegador, también se borrarán las partidas guardadas.

### Características

- 24 niveles
- 16 tipos de enemigos
- 8 tipos de jefes
- diseño vertical
- efectos de partículas
- escudos visuales
- vibración de pantalla
- disparo con puntería automática
- guardado local
- sonido ON / OFF
- soporte multilingüe

### Solución de problemas

Sin sonido

1. Toca o haz clic en el juego una vez.
2. Comprueba que el botón de sonido esté ON.
3. Permite el sonido en la configuración del navegador.

No se guarda

1. Permite el almacenamiento local o datos del sitio.
2. No uses modo incógnito.
3. Prueba con otro navegador.

No funciona

2. Comprueba que el archivo se llame index.html.
3. Arrastra el archivo al navegador.
